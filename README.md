# ISTQB CTFL v4.0 Exam Trainer

An offline, single-page exam app for practicing with the official ISTQB® Certified
Tester Foundation Level v4.0 sample exams. No install, no server — just open
`index.html` in a browser (Edge/Chrome/Firefox).

## How to use

Double-click **`index.html`**, or drag it into a browser window.

1. **Pick an exam set** — A, B, C, D (the official 40-question sample exams, in
   syllabus order) or **MIX** (40 random questions drawn from all four sets plus
   exam A's 26 additional questions — different every time).
2. **Pick a mode:**
   - **Mock exam** — 60-minute countdown timer, 40 questions, no feedback until
     you submit. Pass mark is **65%** of points, just like the real exam.
   - **Practice** — no time limit, same 40 questions, with instant feedback:
     after you press *Check answer* you see whether you were right or wrong and
     the full official explanation (why each option is correct or not).
3. Optional **shuffle** toggle randomizes question order.

## Features

- Sidebar **calculator** (click or type; supports + − × ÷ %) and **notepad**
  (auto-saved per exam, downloadable as a .txt file)
- **Back/forward navigation** — Previous/Next buttons, arrow keys, or jump
  directly via the question navigator grid
- **Keyboard answering** — press `a`–`e` to select, `Enter` to check (practice)
- Multi-select questions (e.g. "select TWO") supported, with correct letter
  combinations from the official answer keys
- **Exhibits** — decision tables, state transition tables/diagrams and the
  traceability matrix are recreated as clean HTML/SVG
- **Results & review** — score, pass/fail verdict, per-chapter breakdown, and a
  full review of every question with the official explanation
- **Resume** — an unfinished exam is remembered (per browser) and can be resumed
- Dark mode (🌙/☀️ toggle)

## Question data

All 166 questions and their official answers, learning objectives, K-levels and
explanations come from the official sample exam documents (in `extracted/`):

| Set | Questions | Extras | Exhibits |
|-----|-----------|--------|----------|
| A   | 40        | 26 additional (A1–A26) | execution-log table (Q14), grade table (Q21), decision table (Q22), state transition diagram (Q23), planning-poker table (A20) |
| B   | 40        | —      | decision table (Q22), state transition diagram (Q23), effort table (Q31), priority figure (Q32), execution log (Q38) |
| C   | 40        | —      | state transition diagram (Q23), control-flow graph (Q24), effort bar chart (Q31), dependency figure (Q32) |
| D   | 40        | —      | decision table (Q22), state transition table (Q23), traceability matrix (Q32) |

The data files (`data/exam[ABCD].js`) were generated by `tools/parse-exam.js`
from the extracted PDF text, with a three-way validation for every question:
section answer ⇄ answer-key table ⇄ explanation verdicts ("Is correct" letters
must match the official answer). Exam A's hand-checked key is in
`tools/keyA.json`.

```
tools/              parser + QA harness
selftest.html       QA harness — loads the app headlessly and runs a scripted
                    exam (see below)
```

## QA

`selftest.html` is `index.html` plus `tools/selftest-inject.js`, which
programmatically:

- starts a practice exam (set D), walks every question via the navigation
  buttons, answers all 40 correctly with the official answers, and checks the
  final score is 40/40,
- verifies the exhibits render, that *Check answer* reveals the explanation,
- starts a mock exam (set A) and verifies the 3600 s timer runs and feedback
  stays hidden until submission.

Run it headlessly:

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" \
  --headless --disable-gpu --virtual-time-budget=8000 \
  --dump-dom "file:///C:/Users/dd636/Desktop/ISTQB/selftest.html" | grep -o "SELFTEST\[.*\]"
```

Every assertion passing shows up in the single `SELFTEST[...]` line.
